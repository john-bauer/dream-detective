# Dream Detective (Frontend)

A simple React frontend that connects to a corresponding server-side AI agent, whose purpose is to provide interpretations about your dreams.

## Getting Started

A recent version of NPM is the only requirement for this part of the project.

All you need to run to get this project running is:

```bash
# Install deps
npm install

# Run the app
npm run dev

# Alternatively, build the production app with:
npm run build

# And serve the production app with:
npm run preview
```

## Project Setup

This project was scaffolded using `npm create vite@latest my-app -- --template react`. I opted to use the non-experimental vite configuration (rollup), as opposed to the experimental rolldown feature.

## Technologies Used

Below are some of the technologies I'm using for this project:

- [React.js](https://react.dev/): v19
- [Vite](https://vite.dev/): Bundles and serves the application.
- [TypeScript](https://www.typescriptlang.org/): JavaScript with types.
- [React Router](https://reactrouter.com/): v7, Handles routing.
- [TailwindCSS](https://tailwindcss.com/): UI library of choice.
- [ESLint](https://eslint.org/): Linter with a basic configuration for TS.
- [React Markdown](https://github.com/remarkjs/react-markdown): Handles markdown rendering.
